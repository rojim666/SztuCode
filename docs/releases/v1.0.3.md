# SztuCode v1.0.3

本次更新依据 `chore(release): 桌面端版本对齐到 1.0.2`（`db50b05`）之后至 `0f167e1` 的 27 条非合并提交整理，不包含该基准提交。

## 桌面工作台

- 新增上下文演进视图，聚合逐轮上下文快照并展示差异，按来源呈现压缩、干预与系统注入；支持从相关记录定位工作区文件，改善上下文查看器可读性。
- 技能可作为可移除的内联令牌随提示词提交；斜杠菜单展示技能及加载状态，技能中心支持一键将技能带入对话，并补齐内置技能和插件图标。
- 已归档、已完成任务支持恢复；修复临时任务在刷新、首次发送和追问后错误关联项目的问题。
- 将“全部任务”并入设置面板的任务分区，精简侧栏入口，跨页导航时保持工作区挂载。
- 新增设置页应用更新检查入口并接入 Tauri updater。当前默认构建尚未配置更新源和公钥，请通过本 Release 安装包手动更新。
- 完善 TypeScript 多模态图片工作流，覆盖图片附件、会话图片保存、模型请求与图片预览。
- 优化品牌字标、界面字号缩放、设置面板、首页启动器与 Beta 标识；改善命令面板、技能标签和壁纸模式输入卡片。
- 修复输入框实际输入及中文组合输入时的占位文字显示，改善思考内容 Markdown 渲染和轮次导航键盘滚动。

## 模型与运行时

- 支持按模型厂商解析 API 密钥及 Base URL，增加 OAuth Access Token 兜底，并提供 OpenRouter、GitHub Models 的 OAuth 登录入口。
- Python Run 引入墙钟截止时间，Agent Loop 增加 LLM Hard Cutoff，并为 Provider 请求超时与重试增加预算边界。
- 修复权限审批响应的运行与会话归属校验，拒绝重复的待审批工具 ID，并明确返回已处理、未知或归属不匹配状态（#118）。
- Python 与 TypeScript 运行时补充逐轮上下文快照；修复普通工具结果未保留在上下文中的问题。
- 集成并统一 Sztubuddy 提示词、技能与 Agent 资源，减少初始提示词注入，修复资源模块兼容性及 Linux 大小写路径问题。

## 开发与文档

- 新增 prompt-studio 提示词调试台与 npm 启动入口。
- 增加英文文档入口。
- 桌面端 npm、Tauri、Cargo 版本及对应锁文件统一为 1.0.3。

## 安装

- Windows x64：`SztuCode_1.0.3_x64-setup.exe`（NSIS）或 `SztuCode_1.0.3_x64_zh-CN.msi`（WiX）。
