# SztuCode 1.0.7

本次版本聚焦桌面工作台的会话与项目交互细节。

## 修复与改进

- 优化会话区项目切换控件的圆角、展开状态和交互反馈。
- 修复切换到没有历史会话的项目时界面无响应的问题。
- 移除项目条文件夹图标在悬停、聚焦和按下时出现的灰色块。
- 缩小并左对齐“新建任务”按钮，减少侧栏占用空间。
- 修复项目展开状态长期显示为聚焦底色的问题。

## 下载与更新

- 推荐安装：`SztuCode_1.0.7_x64-setup.exe`。
- MSI 安装：`SztuCode_1.0.7_x64_zh-CN.msi`。
- 支持在线更新的已安装版本可在「设置 → 关于」检查更新并安装 1.0.7。
- 本次提供 Windows x64 安装包、签名文件、`latest.json` 和 SHA256 校验文件。

完整变更：https://github.com/rojim666/SztuCode/compare/v1.0.6...v1.0.7
