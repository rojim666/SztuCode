# SztuCode 1.0.3.1 快速修复版

本次快速修复针对长任务中上下文压缩不及时、模型请求容易超限的问题。

> Release 标签为 `v1.0.3.1`。由于 Tauri 和更新器要求三段语义版本号，应用内部版本、安装包文件名及在线更新版本使用 `1.0.4`；从 `1.0.3` 检查更新时会显示 `1.0.4`。

## 修复内容

- 桌面端默认自动压缩阈值从 90% 提前到 70%。
- 在每次模型请求前检查输入预算，计入工具定义并预留模型输出空间；恢复历史会话时也会检查。
- 接近窗口上限时等待摘要完成，必要时绕过冷却时间缩小保留窗口，减少摘要尚未完成就继续发送超限请求的情况。
- 修正工具执行后压缩判断漏计缓存 token 的问题。
- 不足 5 个执行轮次时优先保留最新完整工具交互，避免将刚得到的结果一起摘要掉。
- 若压缩后仍无法容纳输入，明确返回预算错误，而不是继续发送已知超限的请求。

工具结果卸载仍保持默认关闭，本次没有调整卸载策略。

## 更新方式

- 已安装启用在线更新的 1.0.3：在设置中检查更新，下载安装显示为 `1.0.4` 的修复版本。
- 较早未启用在线更新的安装包：下载本页 Windows x64 EXE 或 MSI 覆盖安装。
- 提供 EXE/MSI 签名、`latest.json` 与 SHA256 校验文件；在线更新沿用既有公钥。

## 验证

- 78 项相关测试与类型检查通过，覆盖 30 次连续工具执行、慢摘要、超长历史恢复及缓存稳定性。
- 上下文摘要仍是有损压缩；单条超大输入、固定系统提示与工具定义本身超出模型窗口时，仍需调整输入或模型配置。
- 本次执行针对性回归，未重跑存在已知失败项的全量测试。
