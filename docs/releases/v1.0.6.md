# SztuCode 1.0.6 快速修复版

修复 Windows 更新安装时，旧版后台 Node / MCP 进程占用 `resources/runtime/node.exe`，导致出现 **Error opening file for writing**、无法覆盖安装的问题。

## 修复内容

- EXE 与 MSI 安装器内置独立的进程清理程序，在覆盖文件前自动结束当前安装目录的主程序和运行时进程，并等待文件占用释放。
- 按进程可执行文件的完整路径匹配，仅清理目标 SztuCode 安装目录，不影响系统 Node、其他项目或其他安装目录。
- 支持残留 Node / MCP 进程、中文和空格路径；EXE 卸载前也会执行清理。
- 清理程序无需依赖 Node 或 PowerShell，运行时不会弹出命令行窗口。若进程权限不足等原因导致清理失败，安装会停止，不会跳过文件留下不完整安装。

## 下载与更新

- 推荐安装：`SztuCode_1.0.6_x64-setup.exe`。
- MSI 安装：`SztuCode_1.0.6_x64_zh-CN.msi`。
- 支持在线更新的已安装版本：在「设置 → 关于」检查更新并安装 1.0.6。
- 如果旧安装器已经卡在报错窗口，请中止旧安装器，下载本次的新安装包重新运行；旧文件不会自动获得该修复。
- 安装前请完成正在执行的任务；安装器会自动结束旧版程序及其运行时进程。
- 本次提供 Windows x64 安装包，沿用既有更新签名公钥，并提供 `.sig`、`latest.json` 和 SHA256 校验文件。

本次是基于 1.0.5 的安装流程修复，保留 1.0.5 的功能更新。
