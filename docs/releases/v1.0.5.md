# SztuCode 1.0.5

本次发布提供 Windows x64 桌面安装包，重点改善文件拖拽、附件工作区和实验性 Agent 决策体验，同时包含 Python 运行时的超时、取消与权限等待修复。

## 桌面端更新

- 修复原生窗口文件拖拽到输入框时的附件接收行为。
- 无项目任务的附件使用隔离工作区，改善文件处理体验。
- 新增实验性 **LLM + Jev Agent 模式**：主模型提出候选动作，Jev 选择动作；置信度不足或服务异常时回退主模型。该功能默认关闭，需要独立的 TypeSafe API Key，在设置 → 通用 → 实验性功能中启用，对下一次运行生效。
- Jev 状态改为增量注入，补充上下文开销评估与时间线展示。
- 加强打包时的文档解析资源校验。
- 延续上一修复版的上下文预算与压缩修复，并继续支持签名在线更新。

## Python 运行时更新（源码 / CLI）

- LLM Provider 连接重试遵守运行截止时间。
- 工具执行统一处理运行截止时间、超时和取消，改善 Bash 子进程清理。
- 权限请求共享运行截止时间，避免审批等待超过任务预算。
- 改善工作区路径隔离，增加会话压缩快照事件。

桌面安装包仍使用 TypeScript daemon；本节 Python 改动适用于从源码运行的 Python daemon / CLI。

## 下载与升级

- **推荐：** `SztuCode_1.0.5_x64-setup.exe`，适用于 Windows x64。
- **MSI：** `SztuCode_1.0.5_x64_zh-CN.msi`，适用于需要 MSI 部署的用户。
- 已启用在线更新的版本：设置 → 关于 → 自动更新，检查并安装 1.0.5；较早版本可下载安装包覆盖安装。
- 上一版本 GitHub 标签为 `v1.0.3.1`，内部版本号为 `1.0.4`；本次统一为 `v1.0.5` / `1.0.5`。
- 附带安装包 `.sig`、`latest.json` 和 `SHA256SUMS-v1.0.5.txt`；更新沿用既有公钥。
- 本次发布仅提供 Windows x64 安装包。
