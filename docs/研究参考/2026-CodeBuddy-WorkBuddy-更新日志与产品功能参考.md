## 对 SztuCode 的参考价值

### 高优先级参考功能（建议近期考虑）⭐⭐⭐

1. **Worktree 任务隔离**：为每个任务创建独立 Git 工作环境，代码改动互不干扰（v5.4.0，Trae 也有此功能）
2. **Git 分支展示与安全切换**：代码开发模式下的原生 Git 集成（v5.4.0）
3. **present_files 统一产物入口**：专门的工具统一管理文件产物并联动预览（v5.1.0）
4. **模型档位记忆**：思考强度、上下文长度等按会话保存，重启后保持选择（v5.4.5）
5. **权限处理优化**：拒绝单步权限仅跳过当前步骤，不中断整个任务；同类权限不重复弹窗（v5.4.4/v5.4.1）
6. **记忆系统入口**：个人面板「记忆与进化」快捷入口，长期记忆可视化与编辑（v5.4.5/v5.3.3）
7. **中间产物隐藏**：只保留最终交付文件，隐藏中间过程文件，减少干扰（v5.4.4）
8. **安全机制增强**：
   - 删除文件备份/回收站机制
   - 沙箱拦截原因可视化
   - 工具循环检测与黑名单
   - 目录写保护
9. **意图识别推荐**：根据当前任务智能推荐 Skill/Plugin/Connector（v5.3.3）
10. **启动性能优化**：关键路径优化、预热延迟、数据库预检修复（多版本持续优化）

### 中期参考功能 ⭐⭐

1. **行业/场景化应用模式**：按场景提供定制化首页、专家、技能组合（v5.5.0）
2. **产物分享体验**：分享入口、微信唤起、本地文件快捷操作、超时提示（v5.4.3）
3. **HTML 预览增强**：支持 ECharts/Chart.js/D3 等外部图表库（v5.3.6）

7. **会话草稿隔离**：不同模式/场景间输入内容不互相覆盖（v5.5.0）
8. **客户端自检工具**：环境问题排查便捷工具（v5.4.0）
9. **每轮运行时间显示**：对话流显示每轮任务耗时（v5.3.11）

## 关键体验细节参考

### 输入交互

| 细节 | 说明 |
|------|------|
| 拖拽添加文件 | 直接拖文件到输入框 |
| 长文本自动收起 | 粘贴长文本自动收起为标签 |
| Enter/Cmd+Enter 区分 | 快捷发送 vs 换行 |
| 输入法兼容 | 修复中文输入法候选词误提交问题 |
| 草稿保留 | 切换场景/会话时保留已输入内容 |
| 草稿隔离 | 不同模式间草稿不互相覆盖 |

### 错误处理与稳定性

| 细节 | 说明 |
|------|------|
| 网络错误区分 | 本地网络失败不被误报为 502，返回明确错误码 |
| 错误提示可阅读 | 错误提示不一闪而过，可完整查看 |
| 模型不支持图片提示 | Toast 引导切换模型，而非按钮无响应 |
| 模型错误不混淆 | 模型服务异常不误报为网络失败 |
| SSE 流式乱码修复 | UTF-8 多字节字符边界截断问题 |
| 重试上下文保留 | 失败重试不丢失上下文 |
| 数据库自动修复 | 启动时预检与修复 WAL、静默丢失检测 |
| 残留进程处理 | 启动时检测并处理残留进程锁 |

### 性能优化

| 方面 | 措施 |
|------|------|
| 启动速度 | 关键路径优化、prewarm 延迟到首屏后、减少子进程开销 |
| 长对话 | 分批写盘、分片让步、超长对话加载优化 |
| 多任务切换 | 网盘 prefetch 与连接并发、减少切换卡顿白屏 |
| 大文件预览 | 防止大体积附件预览卡死客户端 |

## 稳定性修复热点（值得在开发中提前注意）

WorkBuddy 多个版本持续修复的高频问题：

1. **会话/历史相关**：历史记录丢失、会话切换白屏/卡死、恢复异常、pending 消息跨会话显示
2. **流式输出相关**：SSE 乱码、消息重复/截断/错序、思考内容覆盖、流式中断
3. **模型切换相关**：模型记忆丢失、切换后兜底为 Auto、自定义模型配置问题
4. **连接器/MCP 相关**：授权状态异常、连接失败、重连问题、工具列表为空
5. **Windows 兼容性**：中文路径问题、非系统盘访问 denied、终端弹窗、ConPTY 兼容、防火墙限制
6. **文件预览相关**：PDF/Office/HTML 预览空白、文件名含 # 导致问题、图表库加载失败
7. **权限弹窗相关**：重复弹窗、弹窗被覆盖、等待状态被流式帧覆盖
8. **升级相关**：升级后白屏、旧进程残留、快捷方式丢失、数据迁移问题
9. **休眠/弱网相关**：休眠唤醒后通道不可用、弱网断连重连、网络切换同步
10. **内存/性能相关**：长时间运行卡顿、内存增长、大文件/长对话卡死
