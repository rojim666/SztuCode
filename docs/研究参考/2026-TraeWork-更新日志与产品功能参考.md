## 对 SztuCode 的参考价值

### 高优先级参考功能（建议近期考虑）

1. **"+"按钮统一入口**：将 `/` 命令、附件上传、文件引用等整合到单一 "+" 按钮，简化 Composer 界面
2. **删除文件安全机制**：Agent 删除文件时先移入回收站/废纸篓，避免误删损失
3. **我的文件/产物中心**：统一管理会话中生成的图片、HTML、代码等产物，支持快速访问
4. **工作树（Worktree）支持**：为每个代码任务创建隔离的 Git 工作环境，保持主目录整洁
5. **增强记忆系统**：跨会话保存用户偏好和项目规则，在所有功能中复用
6. **任务/会话搜索与置顶**：支持搜索历史会话，置顶重要任务

### 中期参考功能

1. **Design 模式**：专门用于界面设计生成的工作模式
2. **对话悬浮窗最小化**：后台运行时不中断用户工作
3. **产物分享能力**：HTML/对话结果的分享功能
4. **插件/技能自动推荐**：根据当前任务智能推荐可用 Skill
5. **模板库**：预设常用任务模板，降低使用门槛

### 长期方向参考

1. **多端协同（网页+桌面+移动）**
2. **电脑控制能力**：AI 直接操作用户电脑
3. **语音交互讨论**
4. **企业版功能与管理后台**

### UI/UX 细节参考

- 输入框入口整合（+ 按钮）
- 产物预览体验增强（图片滑动、视频内联播放）
- 不强制选择文件夹即可发任务
- 帮助与反馈入口
