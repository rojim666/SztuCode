# Editorial gallery recipe

## Visual thesis

Quiet, cultured, and spatial. Let images, typography, and sequence create an exhibition-like experience.

## Signature

- Use neutral or softly tinted backgrounds, deep ink, and one restrained accent.
- Favor large image fields, precise captions, generous margins, and editorial asymmetry.
- Use thin rules, small folios, and measured typography instead of decorative containers.
- Alternate immersive image slides with analytical or curatorial text slides.
- Treat cropping and sequencing as primary design tools.

## Typography and rhythm

Use a refined display face or display treatment for titles and a clear reading face for captions and essays. Allow silence around a strong artwork, but avoid accidental empty bands. Align captions to image edges and keep metadata consistent.

## Useful silhouettes

- Minimal cover with one artwork and small metadata
- Full-bleed image + narrow caption rail
- Diptych or triptych with shared baseline
- Curatorial statement + pull quote + detail image
- Timeline or provenance page with editorial rules
- Closing index or exhibition notes

## Remix controls

- More museum: increase neutrality, provenance, and measured spacing.
- More magazine: increase typographic contrast and image cropping.
- More experimental: introduce unusual scale, rotation, or sequencing while preserving legibility.
- More commercial: add clearer calls to action, services, or collection information.

## Failure signals

Whitespace has no compositional purpose; images use inconsistent crops; captions float without alignment; every page repeats the same image-left/text-right layout; decorative frames compete with the artwork; the deck feels like a web gallery rather than a presentation sequence.
