The pre-existing jingmei-ppt snapshot includes its own MIT license and visual recipes; its original repository/Trae authorship could not be verified on 2026-09-07. It must not be presented as an official Trae package. Added OpenAI slides (Apache-2.0) from https://github.com/JetBrains/skills/tree/e0f258b5cfed145015cb3e48da9a97947f7c4ed7/slides .
