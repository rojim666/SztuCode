## 二、 履约动词

| 规范术语 | 含义 | 禁用替代 |
| --- | --- | --- |
| 应 / 应当 | 强制性义务（违反构成违约） | 必须 / 一定要 / 得 |
| 不得 | 禁止性义务 | 不能 / 不行 / 不可以 |
| 可以 | 权利性选择（可选可不选） | 能 / 允许 / 有权 |
| 有权 | 明确赋权，可主动行使 | 能够 / 可以主动 |
| 负有 | 承担特定责任 | 要承担 / 负责 |
| 不迟于 | 期限截止前完成 | 在...之前 / 尽快在 |

## 三、 金额与期限

### 3.1 金额表述标准
```
标准格式：人民币【大写金额】元整（¥数字,xxx.xx）

示例：
✅ 人民币壹拾万元整（¥100,000.00）
✅ 人民币壹佰伍拾万叁仟贰佰元整（¥1,503,200.00）
❌ 10 万元
❌ 100000 元
❌ RMB 100,000
```

### 3.3 期限表述
- ✅ **自合同签订之日起【X】个工作日内**
- ✅ **自【YYYY年MM月DD日】至【YYYY年MM月DD日】**
- ✅ **不迟于【YYYY年MM月DD日】**
- ❌ 尽快 / 合理时间 / 及时 / 尽早

## 四、 关键法律术语

### 4.1 违约与救济
| 规范术语 | 定义 |
| --- | --- |
| 违约 | 未按约定履行合同义务 |
| 违约金 | 约定的违约赔偿金额或比例 |
| 损失赔偿 | 违约金不足以弥补实际损失时的补充赔偿 |
| 继续履行 | 要求违约方按原约定继续履行 |
| 解除合同 | 终止合同关系的救济方式 |
| 定金罚则 | 给付定金一方违约丧失定金；收受定金一方违约双倍返还 |

### 4.2 不可抗力
| 规范术语 | 说明 |
| --- | --- |
| 不可抗力 | 不能预见、不能避免且不能克服的客观情况 |
| 情势变更 | 合同订立后客观情况发生重大变化（区别于不可抗力） |
| 免责事由 | 因不可抗力导致不能履行的部分或全部免责 |

### 4.3 争议解决
| 规范术语 | 说明 |
| --- | --- |
| 友好协商 | 争议解决的前置程序 |
| 仲裁 | 由约定的仲裁委员会裁决（一裁终局） |
| 诉讼 | 向约定管辖法院提起诉讼（两审终审） |
| 管辖 | 明确争议解决的地域与层级 |

### 4.4 保密与知识产权
| 规范术语 | 说明 |
| --- | --- |
| 保密信息 | 需明确列举或通过标识界定 |
| 保密期限 | 保密义务的有效期（建议 3-5 年） |
| 职务作品 | 员工因履行职务完成的作品（归单位） |
| 委托作品 | 委托创作完成的作品（著作权归属依约定） |
| 独占许可 | 仅被许可人可使用，许可人也不得使用 |
| 排他许可 | 许可人 + 被许可人可使用，不得再授权第三方 |
| 普通许可 | 被许可人可使用，许可人可再授权多方 |

## 五、 引用法律的标准格式

```
标准：《【法律全称】》第【X】条第【Y】款第【Z】项

示例：
✅ 《中华人民共和国民法典》第五百七十七条
✅ 《中华人民共和国合同法》第六十条第一款
❌ 民法典第 577 条
❌ 合同法 60 条
```
