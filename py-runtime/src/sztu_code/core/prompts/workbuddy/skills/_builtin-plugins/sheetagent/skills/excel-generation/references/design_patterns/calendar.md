# 设计范式：日历/排程型 (calendar.md)

> 适用："日历 / 月历 / 周计划 / 日程 / 排班 / 日期格"，常与计划型组合。
> 可改编蓝图，按需增删；样式数值、防错见 `schema_principle`，此处不复制。

## 1. 布局蓝图（两种，按需选）
- **月历网格**：7 列（周日~周六 或 周一~周日）× N 周行，每格一天，格内放日期 + 事项。
- **日程清单**：日期行 + 事项/时间/负责人列（更接近排班/排程）。

按月拆 sheet（`1月`/`2月`）或单 sheet 月度分区；年度目标类可加 `汇总`。网格月标题合并属复杂布局，先定锚点再推坐标（§2.3/§4.4）。

## 2. 日历型特有增益
- **日期格**：网格布局，月标题可合并；周末列/非本月日期用浅色区分。
- **多彩配色**：按 `schema_principle §6.2` 的日历多彩方案，每月用 openpyxl 设置一个主色，单 sheet 内仍克制。
- 事项清单/备注区可置日历下方或右侧。
- 星期/周次由日期推导（`WEEKDAY`/`TEXT`）；排班时长/工时按加减法。

## 3. 落点
- Sheets：按月 sheet 或月度分区。
- 网格型：先定网格起止范围、周列顺序、月标题合并、事项区位置（锚点）；清单型用标准明细列。
- 样例：日期连续、符合自然月/工作周；空模板保留网格、事项留空。

## 4. 不做
- 不为简单日程清单强行画月历网格（没要"日历视图"就用清单）。
- 单 sheet 内不堆过多高饱和色。
