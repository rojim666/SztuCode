# GB/T 7713 学术论文版式规则

> 依据：GB/T 7713.1—2022《学术论文编写规则》 / GB/T 7713.2—2022《学位论文编写规则》

## 1. 论文整体结构

学术论文标准结构（按顺序）：

```
1. 封面（学位论文必须）
2. 题名页
3. 摘要（Abstract）
4. 关键词（Keywords）
5. 目录（Contents）
6. 符号表（如需）
7. 正文
   7.1 引言/绪论
   7.2 主体章节（理论/方法/实验/结果）
   7.3 结论
8. 致谢（Acknowledgements）
9. 参考文献（References）
10. 附录（Appendices，如需）
11. 索引（如需）
```

## 2. 题名（标题）规范

- 论文题名：简洁、明确，一般不超过 **20 字**
- 副题名用破折号（——）引出
- 中文题名后另起一行写英文题名
- 禁止使用缩略语、化学式、商品名（应首先给出全称）

## 3. 摘要规范

| 类型 | 字数要求 | 格式 |
|------|---------|------|
| 报道性摘要（实验类） | 200-300 字 | 目的、方法、结果、结论四要素 |
| 指示性摘要（综述类） | 100-200 字 | 简述研究范围和主要论点 |
| 英文摘要 | 对应中文字数 | 独立于中文摘要另页 |

摘要格式：
- 不得引用参考文献
- 不得使用公式、图表
- "摘要："或"[摘要]"标识独占一行，小四号黑体

## 4. 关键词规范

- 数量：3-8 个
- 排列：重要程度从高到低
- 分隔：用分号（；）分隔
- 标识："关键词："或"[关键词]"独占一行，后接关键词
- 外文关键词在中文关键词之后另行列出

## 5. 正文标题层级与字体

| 层级 | 示例 | 字体 | 字号 |
|------|------|------|------|
| 一级（章） | 1 绪论 | 黑体 | 三号（15pt） |
| 二级（节） | 1.1 研究背景 | 黑体 | 小三（14pt） |
| 三级（条） | 1.1.1 问题描述 | 黑体 | 四号（12pt） |
| 四级（款） | 1.1.1.1 细分 | 黑体/宋体 | 小四（11pt） |
| 正文 | — | 宋体 | 四号（12pt） |

- 标题序号：采用 1、1.1、1.1.1 层次式编号
- 标题末尾：不加标点（句号除外的标点均不加）
- 最多 4 级标题

## 6. 图（Figure）规范

- 图序：`图 1`、`图 1-1`（章节内编号）或`图 1`（全文连续编号）
- 图题（图说）：位于图下方，居中，小五宋体
- 图注：图说之后，说明图中需解释的内容
- 图中文字：不小于 8pt
- 多幅分图：用 (a)(b)(c) 标注，各分图有独立图说

## 7. 表（Table）规范

- 表序：同图序规则，`表 1` 或 `表 1-1`
- 表题（表头）：位于表格**上方**，居中，小五宋体
- 表注：表格下方，用"注："引出
- 表格样式：**三线表**（顶线 + 表头底线 + 底线，线宽规范见 design-token）
- 表中数据：小数点对齐，单位写在列标题中

## 8. 公式规范

- 公式居中排列，右侧对齐编号
- 编号格式：`(1)`、`(1-1)`，圆括号
- 公式中符号首次出现必须说明含义
- 量和单位使用 SI 国际单位制

## 9. 页面设置（学术期刊标准）

| 项目 | 规格 |
|------|------|
| 纸张 | A4 |
| 上边距 | 3.0cm |
| 下边距 | 2.5cm |
| 左边距 | 3.0cm（装订侧） |
| 右边距 | 2.5cm |
| 正文字体 | 宋体 四号（12pt） |
| 正文行距 | 1.5 倍行距 |

## 10. 页眉页脚

- 页眉：论文题名（奇数页）/ 章节名（偶数页）
- 页码：页面底部居中，阿拉伯数字，Times New Roman 小四
- 前言/目录页码：罗马数字（ⅰ ⅱ ⅲ…）
- 正文页码：阿拉伯数字从第 1 页开始
