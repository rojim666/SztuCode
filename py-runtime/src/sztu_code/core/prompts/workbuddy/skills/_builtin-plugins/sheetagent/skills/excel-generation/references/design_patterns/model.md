# 设计范式：计算模型型 (model.md)

> 适用："预算 / 资产 / 收益 / 成本 / 库存 / 收支 / 测算"，常与统计型组合。
> 可改编蓝图，按需增删；样式数值、防错见 `schema_principle`，此处不复制。

## 1. 布局蓝图（输入-计算-结果三区分离）
- **输入假设区**：浅底，用户填的假设（增长率/费率/单价…），**不放公式**。
- **计算区**：由输入派生的中间计算，公式可追踪。
- **结果/汇总区**：最终指标，强调/加粗。

拆 `输入` + `计算/明细` + `结果/汇总`（简单场景同 sheet 分区）。多区块属复杂布局，先定锚点再推坐标（§2.3/§4.4）。

## 2. 计算模型型特有增益
- **假设集中 + 引用不写死**：公式引用假设单元格，如 `=B5*(1+$B$6)`，不硬编 `=B5*1.05`。
- **可追踪计算链**：每步引用上一步，不跳步硬填。
- 常见公式：差异 `实际-预算`、执行率 `实际/预算`（比率类按 §4.1 保护）、余额 `期初+收入-支出`、库存收支。

## 3. 落点
- Sheets：输入 + 计算/明细 + 结果/汇总（简单场景合并分区）。
- 列：明确哪些是输入（来源=用户填写）、哪些是计算列（引用假设的完整公式、坐标按锚点）。
- 落实：三区配色（输入浅底/计算浅灰/结果强调）、超支/亏损条件格式、假设区不放公式。
- 样例：给一组**自洽的输入假设**，计算/结果随公式联动（模型型样例的关键在假设合理，不是堆数据）。

## 4. 不做
- 不把可由假设推导的结果写死；不让用户手填覆盖计算区（计算区备注说明）。
