# SztuCode

> An open, experimental workspace for university-focused, full-scenario office agents. Code, documents, spreadsheets, slides, and browsers are all agent workbenches.

[中文说明（默认）](README.md) · **English**

SztuCode is a local-first, event-driven, auditable office and coding agent with TypeScript and Python runtimes. It includes a Tauri desktop workbench, command-line clients, document and spreadsheet workflows, browser automation, image generation, permissions, session recovery, and evaluation tooling.
