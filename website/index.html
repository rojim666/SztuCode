终端 TUI

Dual Runtime

TypeScript 与 Python
双语言镜像实现

不是两套独立产品，而是同一套 daemon/client 架构的双语言实现。功能与契约镜像对齐，生态与入口彼此独立。

bash
# 安装依赖
$ npm install

# 构建所有子包
$ npm run build

# 启动桌面工作台（自动拉起 daemon）
$ npm run tauri dev --prefix desktop
// → Tauri 2 窗口启动，自动连接 127.0.0.1:7438

# 或先启动前端 dev server，再启动 Tauri
$ npm run dev --prefix desktop
// → Vite dev server 运行中
$ npm run tauri dev --prefix desktop

Manifesto

技术民主化

这是一个为高校学生营造的实验性场地。任何人都可以来这里实现自己的想法，我们来者不拒。这就是我们理解的技术民主化。

01

开放参与

无论你是哪个学校、什么专业、有没有编程经验，只要你有想法，这里就欢迎你。零配置启动，内置免费模型，打开就能用。

02

透明可理解

不是让人"用黑箱"，而是让人"理解它如何运作"。Agent Loop、工具调用、权限系统全部开源摊开，你不仅能用，还能读懂、能修改。

03

从想法到创造

从使用者到创造者。通过真实的 Issue → PR → Review 流程参与工程协作，在实验中学习，在实践中成长，而不是永远停留在"调用 API"的层面。
