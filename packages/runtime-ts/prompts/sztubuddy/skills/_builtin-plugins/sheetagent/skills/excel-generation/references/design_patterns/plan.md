# 设计范式：计划型 (plan.md)

> 适用："计划 / 安排 / 排期 / 里程碑 / 周期 / 负责人 / 交付"，常与打卡进度型、统计型组合。
> 可改编蓝图，按需增删；样式数值、防错见 `schema_principle`，此处不复制。

## 1. Sheet 结构
单张 `项目计划` / `任务计划` 通常足够；多项目/多阶段并行可按项目或阶段拆 sheet。

## 2. 布局蓝图（两种，按需选）
- **纯任务清单**：标准明细表，一行一任务。
- **任务 + 横向周进度（甘特式）**：左侧任务信息列（任务/负责人/起止/状态），右侧接周期列（`W1…Wn` 或日期），格内标进度。适合"看时间铺排"。甘特周期列属复杂布局，先定锚点再推坐标（§2.3/§4.4）。

## 3. 核心字段与公式（计划型特有）
- 持续天数 `=结束日期-开始日期+1`（加减只需必要空值保护）。
- 状态枚举 `未开始/进行中/已完成/逾期`（数据验证/枚举说明）。
- 进度百分比若由完成项推导 → 计算列；里程碑/优先级/交付物按需。

## 4. 落点
- Sheets：项目计划（+ 需要时加 汇总）。
- 列：任务、负责人、开始/结束、持续天数（计算列）、状态、优先级、交付物、备注。
- 落实：状态条件格式（逾期红/进行中黄/已完成绿；截止<今天且未完成→红字）、冻结表头+筛选、周进度列标记。

## 5. 不做
- 不为简单任务清单强行加甘特周期列（没暗示时间铺排就不加）。
- 不把可推导的持续天数/进度写死。
