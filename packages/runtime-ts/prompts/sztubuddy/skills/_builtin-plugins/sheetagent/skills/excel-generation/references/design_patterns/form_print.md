# 设计范式：表单/打印型 (form_print.md)

> 适用："打印 / 签字 / 提交 / 填报 / 申请 / 考勤 / 登记表"，常与统计型组合（如考勤含出勤合计）。
> 可改编蓝图，按需增删；样式数值、防错见 `schema_principle`，此处不复制。

## 1. 布局蓝图（一页可打印为目标，自上而下）
- **标题区**：合并居中的表单名（表单/打印型**允许合并单元格**）。
- **填报信息区**：填报单位、填报人、日期、部门等抬头。
- **主表区**：明细项表格，边框增强结构。
- **签字栏**：审批/签字/确认，置底。

复杂布局（标题/签字栏合并）先定锚点再推坐标（§2.3/§4.4）。

## 2. 打印型特有增益
- **打印设置（§8.3）**：列多用横向、设打印区、尽量一页容纳、分页延续说明。
- **不依赖颜色**：按 `schema_principle §6.2` 的打印黑白方案，靠 medium 边框 + 加粗建立层级，颜色不作唯一信息载体。
- **行高**：含 wrapText 长文本的数据区不指定固定行高，除非用户明确要求等高（§8.3）。

## 3. 落点
- 单表（表单名）；列 = 明细项字段 + 签字/确认列。
- 先定标题/签字栏合并范围（锚点）；合计类（如出勤合计）仍公式化（`SUM`/`COUNTIF`）；打印方向/打印区/边框用 openpyxl 打印/样式 API。
- 样例按一页容量设计，不硬造大量行。

## 4. 不做
- 非表单/打印场景不滥用合并单元格；不为打印美观牺牲必要数据结构。
