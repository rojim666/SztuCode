# 设计范式：打卡/进度型 (progress.md)

> 适用："打卡 / 完成 / 进度 / 学习 / 习惯 / 训练 / 检查项"，常与计划型组合（计划型偏排期，进度型偏周期打卡+完成率统计）。
> 可改编蓝图，按需增删；样式数值、防错见 `schema_principle`，此处不复制。

## 1. 布局蓝图（两种，按需选）
- **打卡矩阵**：项目/习惯做行，周期（日/周）做列，交叉格标记完成（`☑/☐`）。
- **项目 + 完成统计**：项目、目标次数、完成次数、完成率、状态。复杂布局先定锚点再推坐标（§2.3/§4.4）。

单张 `进度` / `打卡` 表通常足够；多周期汇总再加 `汇总`。

## 2. 核心字段与公式（进度型特有）
- 完成次数：对 `☑`/`已完成` 计数（`COUNTIF`）。
- 完成率 `完成次数 / 目标次数`——比率类，按 §4.1 做分母空值+0值保护、分子空返空白。
- 完成状态：布尔勾选 `☑/☐` 或 `是/否`（居中）。

## 3. 落点
- 列：项目、周期/日期、目标次数、完成次数（计算列）、完成率（计算列）、状态、备注。
- 落实：完成率条件格式（`>=100%` 绿、`<阈值` 红，可用数据条）、勾选列样式、冻结表头。
- 样例：完成次数 ≤ 目标次数、完成率自洽；空模板保留完成率公式、数据空时显空白不报错。

## 4. 不做
- 不把可统计的完成次数/完成率写死；不为单一习惯打卡强行加多 sheet。
