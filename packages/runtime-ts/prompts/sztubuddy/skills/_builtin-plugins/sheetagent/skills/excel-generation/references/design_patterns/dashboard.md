# 设计范式：看板型 (dashboard.md)

> 适用："看板 / 一眼看 / 概览 / KPI / 仪表盘 / 领导汇报"，常与统计型、记录型组合。
> 可改编蓝图，按需增删；样式数值、图表选型、防错一律见 `schema_principle`，此处不复制。

## 1. Sheet 结构
`看板`（KPI + 图表 + 关键汇总，放最前）+ `明细`（支撑数据，供看板引用）；数据量大再加 `汇总`。

## 2. 看板 Sheet 布局蓝图（本范式核心增益）
以"单屏可视"为目标自上而下分区（坐标示意，按实际字段数调整；先定锚点再推公式坐标，§2.3/§4.4）：

| 区块 | 位置示意 | 角色 |
|---|---|---|
| 标题区 | 第 1 行合并居中 | 报表名 + 期间（深色标题色带）|
| KPI 卡片行 | 第 3~4 行，每指标占 1~2 列 | 总量 / 达成率 / 同比 / 环比 |
| 图表区 | KPI 下方（约第 6 行起）| 趋势 + 分类对比 + 占比 |
| 汇总表区 | 图表下方或右侧 | 分维度合计，SUMIF/SUMIFS 引用明细 |

## 3. KPI 卡片（看板特有）
每卡两格：上格指标名（小字、灰），下格数值（大字、加粗）。数值优先用公式引用明细/汇总；达标/预警按 `schema_principle §7` 用 openpyxl 条件格式上色，体现"一眼看出"。

## 4. 落点
- Sheets：看板 + 明细（+ 汇总）；看板各区块先定行范围 / KPI 位置（锚点）。
- 图表 `openpyxl.chart` 引用明细数据区、不孤立造图；明细标准列 + 冻结表头 + 筛选。
- 样例：明细造 8~15 行使 KPI/图表自洽；空模板保留 KPI 公式与图表框架、数据留空不报错。

## 5. 不做
- 不堆超需求的指标卡（要 3 个 KPI 不加 8 个）。
- 不为看板美观牺牲明细的可筛选 / 可追溯。
