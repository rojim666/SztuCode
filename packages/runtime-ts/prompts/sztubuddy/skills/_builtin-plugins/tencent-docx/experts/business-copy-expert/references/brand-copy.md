# 品牌文案写作指南

> 来源标准：品牌传播理论 + 广告学 AIDA 模型 + 广告法

## Goal

帮助创作具有记忆点、情感共鸣和品牌差异化的品牌文案（Slogan、品牌故事、品牌升级公告）。

## Pre-Writing Questions

1. **品牌定位**：品牌是谁？服务谁？解决什么核心问题？
2. **品牌调性**：专业/亲和/年轻/高端/科技/温暖/文艺？
3. **竞品差异**：与竞品相比，你的核心区别是什么？
4. **传播场景**：这段文案用在哪里？（官网/包装/广告/社媒）
5. **用户心智**：你希望用户看完后记住你什么？

## 创意策略模板

### 版本 1：功能利益型

**适用场景**：产品卖点明确、用户决策理性的品类

```
公式：[核心功能] + [量化效果] + [用户感受]
```

**句式骨架**：
- "[动词][时间/条件]，[达成效果]"
- 范例："充电5分钟，通话2小时"（OPPO）

→ 参见 `examples/brand-functional.md`

### 版本 2：情感利益型

**适用场景**：品牌建设期、用户决策感性的品类

```
公式：[情感洞察] + [品牌态度] + [身份认同]
```

**句式骨架**：
- "[你/我们] + [情感状态/价值观]"
- 范例："你本来就很美"（自然堂）

→ 参见 `examples/brand-emotional.md`

### 版本 3：场景代入型

**适用场景**：生活化品牌、高频消费品

```
公式：[痛点场景] + [解决方案] = [品牌名]
```

**句式骨架**：
- "[场景/痛点]，[动词][品牌名]"
- 范例："困了累了喝红牛"

→ 参见 `examples/brand-scenario.md`

### 版本 4：态度表达型

**适用场景**：年轻化品牌、态度营销

```
公式：[价值观宣言] → [行动号召]
```

**句式骨架**：
- "[祈使句/短句]"
- 范例："Just Do It"（Nike）

## 品牌故事框架

```
1. 创始人/团队的初心（Why）
2. 遇到的困难/转折（Conflict）
3. 坚持做对的事（Resolution）
4. 品牌理念升华（Meaning）
5. 邀请用户加入（Connection）
```

**关键**：品牌故事不是自传，是"为什么你应该信任我"的答案。

## 品牌升级传播

当品牌需要更名/升级时：

1. **公告文案**：解释为什么变 + 变了什么 + 不变的是什么
2. **价值主张**：新品牌的核心承诺（一句话能说清）
3. **Slogan 候选**：至少提供 3 个方向

## Quality Checklist

- [ ] Slogan 是否 ≤10 个字（中文）或 ≤5 个词（英文）？
- [ ] 是否避开了广告法绝对化用语？
- [ ] 是否有明确的品牌差异化？
- [ ] 目标受众能否在3秒内理解？
- [ ] 是否有情感触发点（不只是信息传递）？
- [ ] 是否提供了 ≥2 个创意方向？
