# 社交媒体文案写作指南

> 来源标准：各平台内容规范 + 社媒营销最佳实践

## Goal

帮助创作适配不同社交平台的高互动率文案。

## Pre-Writing Questions

1. **发布平台**：小红书/抖音/微博/微信公众号/LinkedIn？
2. **内容目标**：种草/品宣/引流/互动？
3. **目标受众**：平台用户画像 + 品牌受众的交集
4. **内容形式**：图文/短视频/长文？

## 平台适配矩阵

| 平台 | 字数 | 调性 | 核心策略 | 关键规范 |
|------|-----|------|---------|---------|
| 小红书 | ≤1000字 | 种草/生活化 | 场景+体验+图文 | 禁导流外链，需标注广告 |
| 抖音 | 前3秒定生死 | 短平快 | Hook+反转+CTA | 黄金前3秒 |
| 微信公众号 | 不限 | 深度/专业 | 长文+故事+干货 | 首段折叠前150字决定阅读 |
| 微博 | 140字 | 话题性 | 热点+互动+态度 | 带话题标签 |
| LinkedIn | ≤3000字 | 专业/商务 | 洞察+案例+观点 | 开头2行是Hook |

## 社媒文案公式

### PAS 公式（万能）
```
Problem（痛点）→ Agitate（放大痛苦）→ Solution（方案）
```

### HOOK 公式（抖音/短视频）
```
Hook（钩子）→ Outcome（结果）→ Obstacle（障碍）→ Knowledge（知识）
```

### 4U 公式（小红书/微博）
```
Useful（有用）+ Urgent（紧迫）+ Unique（独特）+ Ultra-specific（超具体）
```

## 平台专项模板

### 小红书种草笔记

```
标题：[数字] + [痛点/效果] + [emoji]
正文：
├── 开头：场景代入 / 个人体验（真实感）
├── 产品介绍：使用感受 > 参数罗列
├── 对比/测评：有对比更有说服力
├── 价格评价：是否值得
└── 总结推荐：适合谁 + 不适合谁
标签：#品类 #关键词 #场景
```

→ 参见 `examples/social-xiaohongshu.md`

### 抖音短视频脚本

```
0-3秒：Hook（制造好奇/冲突/共鸣）
3-10秒：产品展示（痛点→解决方案）
10-13秒：使用效果/用户证言
13-15秒：CTA（点击链接/关注/评论）
```

→ 参见 `examples/social-douyin.md`

### LinkedIn 帖子

```
第1行：Hook（数据/洞察/反直觉观点）
第2行：[空行，制造折叠悬念]
正文：故事/案例/洞察展开
结尾：开放式问题（引导评论互动）
```

→ 参见 `examples/social-linkedin.md`

## Quality Checklist

- [ ] 是否适配了目标平台的调性和格式规范？
- [ ] 开头是否有足够的吸引力（3秒法则）？
- [ ] 是否避免了跨平台复制粘贴（一稿多发）？
- [ ] 是否包含了合适的 CTA？
- [ ] 小红书/抖音是否标注了广告（如为商业推广）？
