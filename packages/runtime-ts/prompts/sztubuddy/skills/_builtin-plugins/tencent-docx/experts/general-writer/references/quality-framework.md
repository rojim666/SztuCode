# 通用写作质量评估框架（7 维打分）

> 本文件是 L1 General Writer 的**质量尺规**，由 Critic 引擎在 Adversarial Critic 阶段强制加载。
>
> 所有通用写作任务必须在**以下 7 个维度**独立打分（0-100），最终加权求总分。

---

## 一、 七维度定义

### D1：事实准确性（权重 20%）
- **定义**：文中提到的事实、数据、引用是否准确无误。
- **扣分项**：
  - 引用数据未标明来源：-10
  - 事实性错误（人名、时间、地点错误）：-30（严重）
  - 编造引用、虚构研究：-50（致命）
- **合格线**：≥ 70

### D2：逻辑严密性（权重 20%）
- **定义**：论点之间的因果、递进、对比关系是否自洽。
- **扣分项**：
  - 论点之间跳跃，缺少衔接：-10
  - 出现自相矛盾：-20
  - 结论与前文不匹配：-15
- **合格线**：≥ 70

### D3：结构清晰度（权重 15%）
- **定义**：整体结构是否有清晰的起承转合 / 总分总 / 分层论证。
- **扣分项**：
  - 没有明确段落划分：-10
  - 长段落不分层（超过 300 字的大段落）：-5/段
  - 无法概括段落核心（段落没有中心句）：-5/段
- **合格线**：≥ 70

### D4：语言精炼度（权重 15%）
- **定义**：是否存在冗余、啰嗦、车轱辘话。
- **扣分项**：
  - 重复表达同一观点：-5/处
  - 使用"总的来说"、"综上所述"等废话开头超过 2 次：-5
  - 单句超过 80 字未断：-3/处
- **合格线**：≥ 70

### D5：风格一致性（权重 10%）
- **定义**：全文语气、人称、风格是否前后统一。
- **扣分项**：
  - 第一/第三人称混用：-10
  - 正式/口语化风格混乱：-10
  - 中英混杂不规范（如无对应概念时的英文堆砌）：-5/处
- **合格线**：≥ 70

### D6：受众适配度（权重 10%）
- **定义**：表达是否符合目标读者的认知水平与关注点。
- **扣分项**：
  - 面向外行却使用大量专业术语不解释：-15
  - 面向专家却过度口语化：-10
  - 文中未体现对读者利益的关照：-10
- **合格线**：≥ 65（此维度较灵活）

### D7：创新与洞察（权重 10%）
- **定义**：是否有超越"罗列信息"的独特观点、类比、见解。
- **加分项**：
  - 提出新颖的类比或隐喻：+10
  - 给出反直觉但合理的结论：+10
  - 整合多源信息形成新洞察：+15
- **合格线**：≥ 60（此维度为鼓励性）

---

## 二、 加权总分计算

```
总分 = D1×0.20 + D2×0.20 + D3×0.15 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.10
```

**通过阈值**：总分 ≥ 75。

**单维度否决**：任一维度 < 60，即使总分达标，也必须重写该维度对应段落。

---

## 三、 Critic 输出格式要求

Critic 在审查时必须以以下结构化格式输出，便于 Harness 解析：

```markdown
## 七维评分报告

### D1 事实准确性：82/100
- 扣分：引用《XX报告》数据未标来源（-10）
- 修改建议：补充 "数据来源：XX研究院《2024 年度报告》"

### D2 逻辑严密性：75/100
- 扣分：第 3 段论点缺少过渡（-10）
- 修改建议：在第 3 段首句前增加承接句 "基于此..."

...（依此类推 D3-D7）

### 加权总分：78.5 / 100
### 是否通过：✅ 通过（总分 >= 75，且无维度 < 60）

### 需要重写的段落：
- 第 3 段（逻辑问题）
- 第 5 段（用词啰嗦）
```

---

## 四、 字数与风格匹配

详见 `doc-type-matrix.md`，不同文体有不同的字数与风格基准。本评分框架的 D3（结构）、D4（语言）、D5（风格）应结合 `doc-type-matrix.md` 的基准值做相对评判。
