# B2B Cold Email 范例

`展示如何写一封让技术决策者愿意回复的 Cold Email`

## 范例：向互联网公司技术 VP 推销 API 网关

%% 句式骨架：[个性化破冰] → [你的问题] → [我的方案] → [证明] → [低门槛CTA]
%% 特点：不像营销邮件，像同行请教

### 完整邮件

```
Subject: [公司名] 的 API 网关——有个想法想跟你聊聊

Hi [Name],

看到你们上个月发布了开放平台 2.0，API 接入量应该涨了不少。

我们之前帮 [类似公司] 解决过类似的问题——API 量从日均
500万涨到3000万的时候，Kong 开始扛不住了。换到我们的
网关后，P99 延迟从 180ms 降到了 60ms，而且不用改一行
业务代码。

如果你们也遇到了类似的痛点，方便这周找15分钟聊一下？
不推销，纯交流。

[签名]
[Name] | [Title]
[Company] | [Phone]
```

### 逐句解析

%% 第1句：个性化破冰——证明"我做过功课，不是群发"
`看到你们上个月发布了开放平台 2.0，API 接入量应该涨了不少。`
→ 提及对方公司的具体动态，建立 relevance

%% 第2-3句：pain point + social proof
`我们之前帮 [类似公司] 解决过类似的问题...`
→ 不说"我们的产品有多好"，而是"跟你类似的公司用我们做到了什么"

%% CTA：低门槛
`方便这周找15分钟聊一下？不推销，纯交流。`
→ "15分钟"降低承诺感，"不推销"降低防御心

### Cold Email 的关键数据

| 要素 | 最佳实践 | 原因 |
|------|---------|------|
| 标题长度 | ≤40字符 | 移动端完整显示 |
| 正文长度 | ≤150词 | Boomerang 数据：75-100词回复率最高 |
| CTA 门槛 | 15分钟电话 | 远低于"购买/Demo/注册" |
| 个性化 | 提及对方公司/最近动态 | 回复率提升 2-3x |

### 反模式对照

```
❌ Subject: "业界领先的API网关解决方案"
   → 像垃圾邮件，秒删

❌ "尊敬的先生/女士，我司是一家专业从事..."
   → 群发模板，零个性化

❌ "请问贵公司是否有API网关方面的需求？"
   → 把调研的工作丢给对方

✅ "看到你们上个月发布了开放平台 2.0"
   → 证明我研究过你，你不是第10000个收件人
```
