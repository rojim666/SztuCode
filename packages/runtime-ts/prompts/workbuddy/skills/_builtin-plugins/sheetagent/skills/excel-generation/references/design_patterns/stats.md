# 设计范式：统计型 (stats.md)

> 适用："统计 / 汇总 / 分析 / 报表 / 排名 / 占比 / 趋势"，常与记录型（明细底表）、看板型组合。
> 可改编蓝图，按需增删；样式数值、图表选型、防错见 `schema_principle`，此处不复制。

## 1. Sheet 结构
`明细`（原始行级数据）+ `汇总`（按维度聚合、引用明细，**统计型核心**）；可视化强时汇总内嵌图表或并入看板。

## 2. 汇总 Sheet 布局蓝图（本范式核心增益）
维度做行、指标做列的交叉汇总。通常有标题行/合计行，属复杂表——先定锚点再推公式坐标（§2.3/§4.4）：

| 区块 | 位置示意 | 角色 |
|---|---|---|
| 标题区 | 第 1 行合并居中 | 报表名 + 期间 |
| 表头行 | 第 2 行 | 维度名 + 各指标名 |
| 数据区 | 第 3 行起 | 每行一维度值，指标列为跨表聚合公式 |
| 合计行 | 数据区下方 | 各指标列求和 / 加权 |

## 3. 聚合与派生字段（统计型特有）
能公式化的一律公式化（§4.1/§4.2），跨表直接引用明细：
- 分组合计 `SUMIF`/`SUMIFS`（如 `=SUMIF(明细!B:B,A3,明细!D:D)`）；计数 `COUNTIF`/`COUNTIFS`
- 占比 / 达成率 / 同比 / 环比：比率类，按 §4.1 做分母空值+0值保护、分子空返空白
- 排名 `RANK`/`RANK.EQ`

## 4. 落点
- Sheets：明细 + 汇总（+ 看板）。
- 汇总列：维度列（推断）+ 指标列（计算列，完整跨表公式、坐标按锚点）；先定合计行位置。
- 图表放汇总 sheet 引用数据区（按 §9 选型）；只要静态汇总数字则不加图。
- 样例：明细造合理样例、汇总随公式自洽；空模板明细空时公式显空白不报错。

## 5. 不做
- 不把可聚合结果手填写死；不在明细里混汇总行破坏可筛选（汇总另置）。
