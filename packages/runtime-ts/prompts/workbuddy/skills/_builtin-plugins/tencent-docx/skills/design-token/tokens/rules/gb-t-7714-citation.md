# GB/T 7714 参考文献著录格式规则

> 依据：GB/T 7714—2015《信息与文献 参考文献著录规则》

## 1. 文献类型标识码

| 文献类型 | 标识码 | 说明 |
|---------|-------|------|
| 专著 | M | 图书、专著 |
| 连续出版物 | J | 期刊 |
| 论文集 | C | 会议论文集 |
| 论文集析出文献 | A | 会议论文（单篇） |
| 学位论文 | D | 博士/硕士论文 |
| 报告 | R | 科技报告 |
| 标准 | S | 国家/行业标准 |
| 专利 | P | 专利文献 |
| 数据库 | DB | 数据库 |
| 计算机程序 | CP | 软件 |
| 电子公告 | EB | 网页、电子邮件 |

## 2. 著录格式规范

### 2.1 专著（M）

```
[序号] 主要责任者. 题名: 其他题名信息[文献类型标识]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

示例：
```
[1] 傅书华. 史铁生论[M]. 太原: 山西人民出版社, 1997: 10-12.
[2] PEEBLES P Z Jr. Probability, Random Variables, and Random Signal Principles[M]. 4th ed. New York: McGraw-Hill, 2001: 105.
```

### 2.2 期刊论文（J）

```
[序号] 主要责任者. 题名[J]. 期刊名, 出版年, 卷(期): 起止页码. DOI.
```

示例：
```
[1] 袁训来, 陈哲, 肖书海. 蓝田生物群: 一个认识多细胞生物起源和早期演化的新窗口[J]. 科学通报, 2012, 57(34): 3219-3227.
[2] YU G, WANG L G, HAN Y. clusterProfiler: an R Package for Comparing Biological Themes Among Gene Clusters[J]. OMICS: A Journal of Integrative Biology, 2012, 16(5): 284-287. DOI: 10.1089/omi.2011.0118.
```

### 2.3 学位论文（D）

```
[序号] 主要责任者. 题名[D]. 保存地: 保存机构, 年份.
```

示例：
```
[1] 张筑生. 微分半动力系统的不变集[D]. 北京: 北京大学数学系, 1983.
```

### 2.4 会议论文（C/A）

论文集整体（C）：
```
[序号] 主要责任者. 题名[C]. 出版地: 出版者, 出版年.
```

论文集中析出的单篇（A）：
```
[序号] 析出责任者. 析出题名[A]//论文集责任者. 论文集题名[C]. 出版地: 出版者, 出版年: 起止页码.
```

### 2.5 标准（S）

```
[序号] 起草责任者. 标准名称: 其他信息[S]. 标准编号. 出版地: 出版者, 出版年.
```

示例：
```
[1] 中国国家标准化管理委员会. 信息与文献 参考文献著录规则[S]. GB/T 7714—2015. 北京: 中国标准出版社, 2015.
```

### 2.6 电子资源（EB/OL）

```
[序号] 主要责任者. 题名[EB/OL]. 出版地: 出版者（或网址）, 出版年（或更新日期）[引用日期]. 获取路径. DOI.
```

示例：
```
[1] 中国互联网络信息中心. 中国互联网络发展状况统计报告[EB/OL]. (2021-02-03)[2021-04-12]. http://www.cnnic.net.cn/hlwfzyj/hlwxzbg/hlwtjbg/202102/P020210203334633480104.pdf.
```

## 3. 著者格式规范

### 3.1 中文著者

- 3 人及以内：全部列出，各著者之间以"，"（逗号）分隔
- 3 人以上：列前 3 名，后加"，等"（或英文 `et al.`）
- 姓名写全名，不用缩写

### 3.2 英文著者

格式：`姓, 名缩写.`
示例：`ZHAO X L` / `SMITH J K`

- 多著者之间用"，"分隔
- 超过 3 人：前 3 名后加 `et al.`

### 3.3 机构著者

直接写机构全称，不缩写。

## 4. DOI 格式

- 必须使用完整 DOI URL 格式：`https://doi.org/10.xxxx/xxxxx`
- 或标注 `DOI: 10.xxxx/xxxxx`
- DOI 放在著录条目最末

## 5. 参考文献列表格式

- 列表标题："参考文献"，黑体四号，居中
- 条目编号：方括号，`[1]`、`[2]`……按正文中引用顺序排序（顺序编码制）
- 或按著者姓名字母顺序排序（著者-出版年制）
- 每条独占一行，悬挂缩进（首行不缩进，后续行缩进 2 字符）
- 字体：宋体五号（9pt），行距 1.0 或 1.15

## 6. 正文中的引用标注

### 6.1 顺序编码制

- 在引用处以上标方括号数字标注：`[1]`、`[2,3]`、`[4-6]`
- 示例：`研究表明[1]...` / `如文献[3,5]所示`

### 6.2 著者-出版年制

- 格式：`(著者, 年份)` 或 `著者(年份)`
- 中文：`（张三，2021）`
- 英文：`(Smith, 2021)` / `Smith（2021）`
- 多著者：`（张三等，2021）` / `(Smith et al., 2021)`

## 7. 常见错误清单

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| 期刊名缩写 | J. Biol. Chem. | Journal of Biological Chemistry |
| 页码省略 | … 2023. | … 2023: 125-130. |
| 年份格式 | '23 | 2023 |
| DOI 格式错误 | DOI:10.1234 | https://doi.org/10.1234/xxx |
| 著者超限不标 | 5 人全列 | 前 3 名, 等. 或 et al. |
| 文献标识码缺失 | 题名. 出版者 | 题名[M]. 出版者 |
