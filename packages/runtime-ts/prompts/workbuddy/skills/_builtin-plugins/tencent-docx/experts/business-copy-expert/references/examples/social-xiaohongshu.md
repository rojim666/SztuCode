# 小红书种草笔记范例

`展示如何写一篇符合小红书社区调性的种草笔记`

## 范例：无线降噪耳机 399 元

%% 句式骨架：[场景共鸣] → [产品体验] → [使用场景] → [价格评价] → [总结]
%% 特点：生活化、真实感、种草而非广告

### 完整笔记

```
🎧 通勤党的救命神器找到了！

坐标北京，每天地铁1号线通勤2小时。
之前试过三四款降噪耳机，不是太贵就是降噪效果一般。

上个月入手了这款 [品牌] 无线降噪耳机，399，
说实话一开始没抱太大期望，结果…

✅ 降噪效果：地铁报站声直接"消失"，
   周围大叔大妈的外放也几乎听不到了
✅ 续航逆天：40小时！！我一周充一次，
   周五还有电（之前那款两天就要充）
✅ 佩戴舒适：带了3小时耳朵不痛，
   这点对通勤党太重要了

唯一小缺点：充电盒有点大，
放牛仔裤口袋略鼓，大衣口袋就没问题

📌 适合谁：
- 每天通勤超过1小时的打工人
- 预算有限但想要降噪的同学
- 讨厌频繁充电的懒人（比如我）

📌 不太适合：
- 追求极致音质的发烧友
- 需要专业主动降噪的（建议上千元档）

399这个价位，我觉得性价比拉满了 🫡

#通勤好物 #降噪耳机 #打工人必备 #数码好物分享
```

### 逐句解析

%% 标题策略：痛点场景 + 情绪词 + emoji
`🎧 通勤党的救命神器找到了！`
→ "通勤党"锁定人群，"救命神器"制造好奇

%% 开头：个人场景代入，建立真实感
`坐标北京，每天地铁1号线通勤2小时`
→ 具体地点+时间，不是广告是真实分享

%% 产品体验：感受 > 参数
`地铁报站声直接"消失"`
→ 不说"降噪38dB"，说用户能感知的效果

%% 诚实缺点：增加可信度
`唯一小缺点：充电盒有点大`
→ 有缺点反而更真实，增加种草说服力

%% 适合/不适合：帮用户做决策
→ 降低"看了不知道适不适合我"的犹豫

### 反模式对照

```
❌ "这款耳机采用最新蓝牙5.3芯片，支持LDAC编码..."
   → 参数堆砌，小红书用户不看

❌ "全网最低价！！！限时抢购！！！"
   → 小红书反感硬广

✅ "坐标北京，每天地铁1号线通勤2小时"
   → 场景代入，真实感
```
