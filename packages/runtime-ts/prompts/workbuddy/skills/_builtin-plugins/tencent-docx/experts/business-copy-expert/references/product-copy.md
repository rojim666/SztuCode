# 产品文案写作指南

> 来源标准：FAB 法则 + 消费者决策理论 + 电商平台规范

## Goal

帮助创作能驱动转化的产品文案——卖点提炼、详情页、产品介绍。

## Pre-Writing Questions

1. **产品定位**：在品类中属于什么价位段？核心竞争力是什么？
2. **目标用户**：谁会买？购买决策的关键考量是什么？
3. **使用场景**：用户在什么场景下使用？解决什么具体问题？
4. **价格策略**：需要做价格正当化吗？（高价产品必须回答"为什么值这个价"）
5. **竞品对比**：用户可能会拿什么产品来比较？

## FAB 卖点提炼法

```
Feature（特征）→ Advantage（优势）→ Benefit（利益）

示例：
  Feature:   采用 Type-C 接口
  Advantage: 充电速度提升 50%
  Benefit:   午休30分钟，电量从20%充到80%，下午不焦虑
```

**关键**：用户不关心 Feature，只关心 Benefit。每个卖点必须落到用户利益。

## 产品描述结构模板

### 版本 1：标准电商详情页

```
1. 一句话价值主张（Hook）
2. 3-5个核心卖点（FAB 展开）
3. 使用场景描述（帮用户想象拥有后的生活）
4. 社会证明（用户评价/数据/奖项）
5. 行动号召（CTA）
```

→ 参见 `examples/product-detail-page.md`

### 版本 2：高价产品（价格正当化）

```
1. 品类认知重塑（"这不只是一个XX"）
2. 工艺/材料/技术差异（为什么成本高）
3. 长期价值算账（日均成本 or 使用寿命）
4. 对标高端品牌（"XX同等级材料"）
5. 用户证言（已购用户的真实感受）
```

→ 参见 `examples/product-premium.md`

### 版本 3：B2B/SaaS 产品

```
1. 痛点共鸣（你是否遇到过…）
2. 解决方案概述（一句话说清楚）
3. 核心能力矩阵（3-5个核心功能 + 对应价值）
4. 客户案例/数据证明
5. 免费试用/Demo CTA
```

→ 参见 `examples/product-saas.md`

## Quality Checklist

- [ ] 每个卖点是否都落到了用户利益（Benefit）而非功能（Feature）？
- [ ] 是否有具体数字支撑（而非空泛形容词）？
- [ ] CTA 是否明确、单一？（一个按钮 > 多个按钮）
- [ ] 高价产品是否回答了"为什么值这个价"？
- [ ] 是否避免了自嗨型表述（"我们如何厉害"）？
