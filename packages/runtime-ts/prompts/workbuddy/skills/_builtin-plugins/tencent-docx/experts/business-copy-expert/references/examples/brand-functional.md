# 功能利益型 Slogan 范例

`展示如何用 [功能] + [量化效果] + [用户感受] 公式创作品牌 Slogan`

## 范例 1：OPPO 闪充

%% 句式骨架：[动词+时间条件]，[达成效果]
%% 特点：极简对偶结构，数字对比制造记忆点

**文案**：充电5分钟，通话2小时
**策略分析**：
- 把技术参数（65W闪充）翻译成用户场景
- 「5分钟 vs 2小时」的数字对比产生强烈冲击
- 不说"我们的充电技术很快"，而是说"你能做到什么"

## 范例 2：健康轻食品牌（仿真）

%% 句式骨架：[痛点否定] + [利益承诺]
%% 特点：先否定传统认知，再给新答案

**用户需求**：25-35岁都市白领，主打科学配比+方便+美味
**文案方向 A**（功能利益）：
> 一顿饭的时间，一整天的能量

**策略**：场景（一顿饭）→ 效果（一整天），时间对比
**解析**：
- "一顿饭的时间"暗示方便快捷
- "一整天的能量"暗示科学配比
- 没有直接说"方便"或"营养"，而是让用户自己感受

**文案方向 B**（情感+功能）：
> 认真吃饭，是对自己最小的善意

**策略**：情感洞察（白领忙到没空好好吃饭）→ 品牌态度
**解析**：
- 痛点不是"没东西吃"，是"没时间好好吃"
- 把"吃轻食"重新定义为"对自己好"

## 反模式对照

```
❌ "采用先进营养配比技术，富含12种维生素和矿物质"
   → 自嗨型，罗列参数，用户无感

❌ "最好吃的轻食品牌"
   → 广告法违禁词"最"

✅ "一顿饭的时间，一整天的能量"
   → 功能利益翻译成用户场景
```
