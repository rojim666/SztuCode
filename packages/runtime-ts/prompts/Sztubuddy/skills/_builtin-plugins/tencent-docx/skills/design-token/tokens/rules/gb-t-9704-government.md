# GB/T 9704 党政机关公文格式规则

> 依据：GB/T 9704—2012《党政机关公文格式》国家标准

## 1. 页面设置

| 项目 | 规格 |
|------|------|
| 纸张规格 | A4（210mm × 297mm） |
| 页边距（上） | 3.7cm（含页眉区域） |
| 页边距（下） | 3.5cm（含页脚区域） |
| 页边距（左） | 2.8cm（装订侧） |
| 页边距（右） | 2.6cm |
| 正文区域宽度 | 约 156mm（22 字 × 14pt） |
| 正文区域高度 | 约 225mm（不含页眉页脚） |

## 2. 字体与字号规定

| 版面要素 | 字体 | 字号 |
|---------|------|------|
| 发文机关标志（红头） | 小标宋体（加粗）| 二号（22pt） |
| 文件标题 | 小标宋体 | 二号（22pt），居中 |
| 一级标题 | 黑体 | 三号（16pt） |
| 二级标题 | 楷体 | 三号（16pt） |
| 三级标题 | 仿宋（加粗） | 三号（16pt） |
| 正文 | 仿宋 | 三号（16pt） |
| 附件名称 | 仿宋 | 三号（16pt） |
| 页码 | Times New Roman / 仿宋 | 四号（14pt） |
| 版记内容 | 仿宋 | 四号（14pt） |

## 3. 行距规定

- 正文行距：**28 磅**（固定值，不随字号变化）
- 标题行距：可适当调整（标题较短时居中排列）
- 间隔线（红色横线）：位于文件标题与正文之间，贯通左右

## 4. 标题层级与编号

公文标题层级编号规范（从上至下）：

```
第一层：一、二、三……（汉字数字，句号结束）
第二层：（一）（二）（三）……（汉字数字，圆括号，无标点）
第三层：1. 2. 3.……（阿拉伯数字，句号结束）
第四层：（1）（2）（3）……（阿拉伯数字，圆括号）
```

- 各层级单独占行，无缩进（与正文左对齐）
- 标题中的数字和年份使用**阿拉伯数字**

## 5. 发文字号格式

格式：`[机关代字〔年份〕序号号]`

示例：`国办发〔2023〕15号`

- 机关代字：发文机关简称 + 文种简称
- 年份：用六角括号（〔〕）括注，4 位完整年份
- 序号：阿拉伯数字，不加"第"字，不含前置零
- 结尾：加"号"字

## 6. 版记格式

位于最后一页正文（或附件）末尾之后：

- 版记各要素之间用"印发机关和印发日期"横线分隔
- 抄送机关：字体仿宋三号，"抄送："后接机关名称，多个机关用"、"隔开，句末用"。"
- 印发机关和日期：印发机关左空一字，印发日期右空一字，用汉字书写年月日

## 7. 附件格式

- 附件序号用阿拉伯数字：`附件：1.xxxx`
- 附件题名后不加标点
- 正文附件说明位于正文最后一段之后，最后一个附件题名后加句号

## 8. 日期书写

- 正式公文中的日期一律使用**汉字**书写
- 示例：`二〇二三年六月十五日`（含"〇"而非"零"）

## 9. 禁止事项

- ❌ 正文不得首行缩进（公文格式无缩进）
- ❌ 标题不得加下划线
- ❌ 不得使用艺术字或装饰性字体
- ❌ 文件编号不得使用简写年份
