# Scripts (占位)

> 本目录用于存放 `legal-contract-expert` Skill 所需的可执行辅助脚本。
>
> **当前为占位状态**。未来可能包含的脚本示例：
> - `contract_template_filler.py`：按模板自动填充合同占位符
> - `terms_validator.py`：扫描合同中的术语是否匹配 `references/terms-library.md`
> - `amount_checker.py`：校验金额大小写并列格式
>
> 新增脚本时请遵循 `../../../../docs/standards/skill-standard.md` 第四章规范。
