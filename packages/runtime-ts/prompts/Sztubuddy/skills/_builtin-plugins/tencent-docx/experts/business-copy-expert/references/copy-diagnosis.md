# 文案诊断指南

> 来源标准：AIDA 模型 + 广告法 + 文案五维度评估体系

## Goal

帮助评估现有文案质量，识别问题并输出优化方案。

## 评价标准体系

### AIDA 达成度检测
```
A - Attention：标题/首句能否在3秒内抓住注意力？
I - Interest：是否激发了进一步了解的兴趣？
D - Desire：是否唤起了拥有/行动的欲望？
A - Action：CTA 是否明确有力？
```

### 文案质量五维度
| 维度 | 权重 | 评价标准 |
|------|------|---------|
| **吸引力** | 25% | 标题/首句能否在3秒内抓住注意力 |
| **信息传达** | 25% | 核心卖点/价值主张是否清晰传达 |
| **情感共鸣** | 20% | 是否触发目标受众的情感连接 |
| **行动驱动** | 15% | CTA 是否明确有力 |
| **品牌一致** | 15% | 语调、风格是否与品牌调性一致 |

### 广告法红线（绝对禁止）

| 类别 | 违禁词示例 | 法律后果 |
|------|----------|---------|
| 绝对化用语 | 最、第一、唯一、顶级、极致 | 罚款20-100万 |
| 虚假承诺 | 包治百病、100%有效、永久 | 罚款+吊销执照 |
| 贬低竞品 | 直接或暗示竞争对手差 | 不正当竞争 |
| 违禁评比 | 国家级、最高级、最佳 | 罚款20-100万 |

## 诊断输出模板

```markdown
## 文案诊断报告

### 综合评分：X/10

### AIDA 达成度
- A（注意力）：✅/❌ [具体分析]
- I（兴趣）：✅/❌ [具体分析]
- D（欲望）：✅/❌ [具体分析]
- A（行动）：✅/❌ [具体分析]

### 五维度评分
| 维度 | 得分 | 分析 |
|------|------|------|

### 问题清单（按严重程度排序）
1. 🔴 [致命问题]
2. 🟡 [改进建议]
3. 🟢 [优化空间]

### 广告法合规检查
- ✅/❌ [检查结果]

### 优化方案
#### 方向 A：[策略名]
[优化后文案]

#### 方向 B：[策略名]
[优化后文案]
```

## Quality Checklist

- [ ] 是否逐项检测了 AIDA 四要素？
- [ ] 是否进行了广告法违禁词扫描？
- [ ] 是否提供了 ≥2 个优化方向？
- [ ] 问题是否按严重程度排序？
- [ ] 优化方案是否保留了原文案的核心信息？
