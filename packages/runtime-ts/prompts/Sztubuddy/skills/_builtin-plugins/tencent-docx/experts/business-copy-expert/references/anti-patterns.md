# 商业文案反模式清单

> 这些是经过验证的"坑"——看到就要避免

## 致命反模式（必须避免）

### 1. 自嗨型文案
```
❌ "我们拥有业界领先的技术，核心团队来自BAT"
✅ "帮你把3天的工作压缩到30分钟"
```
**问题**：全是"我们如何厉害"，用户无感
**诊断信号**：主语是"我们/本公司/我司"出现 ≥3 次

### 2. 堆砌形容词
```
❌ "高端大气上档次，低调奢华有内涵的极致匠心产品"
✅ "医用级316L不锈钢内胆，经过 2000 小时耐腐蚀测试"
```
**问题**：空洞无物，不提供任何有效信息
**诊断信号**：连续 ≥3 个形容词修饰同一名词

### 3. 广告法违禁词
```
❌ "最好的AI写作工具"、"100%有效"、"永久免费"
✅ "超过10万用户选择的AI写作工具"
```
**问题**：罚款20-100万，品牌声誉损失
**诊断信号**：含"最/第一/唯一/顶级/极致/万能/100%"

### 4. 模糊CTA
```
❌ "欢迎了解更多" / "期待您的光临"
✅ "立即免费试用14天 →" / "扫码领取50元新人券"
```
**问题**：用户不知道做什么，转化率极低
**诊断信号**：CTA 不包含具体动作和利益

### 5. 信息过载
```
❌ 一篇文案塞了 10 个卖点
✅ 1个核心卖点 + 2-3个支撑点
```
**问题**：什么都说 = 什么都没记住
**诊断信号**：文案超过 500 字但没有明确的信息层次

## 严重反模式（应当避免）

### 6. 忽略受众
```
❌ 对 95 后用官方体："兹通知贵用户..."
✅ "嘿，你的会员快到期了 🎫"
```
**问题**：调性不匹配，用户觉得"这不是写给我的"

### 7. 功能罗列无转化
```
❌ "支持PDF/Word/PPT/Excel/HTML格式"
✅ "不管什么格式的文件，拖进来就能用"
```
**问题**：Feature 堆砌但没有翻译成用户利益

### 8. 虚假紧迫感
```
❌ "最后3小时！！！"（实际常年如此）
✅ "早鸟价截止：4月30日 23:59"
```
**问题**：损耗品牌信任

### 9. 忽视移动端阅读体验
```
❌ 邮件标题60个字符，正文全是长段落
✅ 标题 ≤50字符，正文用短段+列表
```
**问题**：60% 的邮件/社媒在手机端阅读

### 10. 复制粘贴式多平台发布
```
❌ 同一段文案同时发小红书、抖音、LinkedIn
✅ 同一核心信息，三种平台适配版本
```
**问题**：每个平台的调性、格式、用户期望完全不同
