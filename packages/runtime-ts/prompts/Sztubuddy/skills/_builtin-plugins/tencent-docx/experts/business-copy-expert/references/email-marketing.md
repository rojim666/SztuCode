# 营销邮件写作指南

> 来源标准：Email Marketing 行业标准 + B2B Sales 最佳实践

## Goal

帮助创作高打开率、高点击率的营销邮件和 Cold Email。

## Pre-Writing Questions

1. **邮件目标**：要用户做什么？（注册/购买/回访/回复）
2. **收件人画像**：谁会收到？什么职位？什么痛点？
3. **关系阶段**：冷启动 / 已注册未使用 / 活跃用户 / 流失用户？
4. **核心利益点**：收件人为什么要花时间读这封邮件？

## 邮件结构模板

### 版本 1：用户激活/唤醒邮件

```
Subject: [痛点/利益] + [好奇心/紧迫感]（≤50字符）
Preview: 补充说明，不重复标题

正文：
├── 开头：个性化称呼 + 共鸣痛点（2-3句）
├── 价值：你的解决方案 + 核心利益（3-5句）
├── 证明：数据/案例/用户证言（2-3句）
├── CTA：明确的行动指引（1句，单一按钮）
└── PS：补充优惠/紧迫感（1句，可选）
```

→ 参见 `examples/email-activation.md`

### 版本 2：B2B Cold Email

```
Subject: [个性化钩子]（≤40字符，不像营销邮件）

正文：
├── 第1句：个性化破冰（提及对方公司/产品/最近动态）
├── 第2-3句：你发现的问题/机会（展示你做了功课）
├── 第4-5句：你的解决方案（一句话，不推销）
├── 第6句：社会证明（"[类似公司]用我们的方案做到了[结果]"）
├── CTA：低门槛请求（"15分钟电话？"而非"购买我们的产品"）
└── 签名：真实姓名+职位（不要花哨模板）
```

→ 参见 `examples/email-cold.md`

## 邮件优化关键数据

| 策略 | 效果提升 | 来源 |
|------|---------|------|
| 标题含数字 | 打开率 +36% | Mailchimp |
| 个性化称呼 | 打开率 +26% | Campaign Monitor |
| 单一CTA | 点击率 +28% | WordStream |
| 移动端适配 | 60%的邮件在手机打开 | Litmus |
| 正文 ≤200 词 | 回复率最优 | Boomerang |

## Quality Checklist

- [ ] 标题是否 ≤50 字符？是否有打开的理由？
- [ ] 是否避免了垃圾邮件触发词（免费/紧急/限时 等过度使用）？
- [ ] CTA 是否单一明确？用户知道下一步做什么？
- [ ] Cold Email 是否展示了"我研究过你"？
- [ ] 正文是否 ≤200 词（Cold Email）或 ≤400 词（营销邮件）？
