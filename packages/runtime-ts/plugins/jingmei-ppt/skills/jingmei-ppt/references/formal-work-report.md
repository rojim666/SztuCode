# Formal work report recipe

## Visual thesis

Rigorous, orderly, and restrained. Make status, deviation, responsibility, decision, and next action easy to scan in a meeting.

## Signature

- Use warm off-white or white backgrounds, near-black text, restrained amber or blue accents, and semantic green/amber/red status colors.
- Prefer flat tables, progress bars, timelines, and decision matrices over ornamental card collections.
- Use compact section labels and moderate claim headlines.
- Build a stable grid with strong column alignment and consistent row logic.
- Use decoration sparingly; let rules, spacing, and type establish authority.

## Typography and rhythm

Keep titles smaller than keynote titles and clearly separated from content. Use medium-size body text and compact rows. When a table feels airy and the copy feels small, reduce row spacing and increase type rather than enlarging the entire table. Let the final panel or conclusion band approach the footer safety zone.

## Useful silhouettes

- Executive summary + progress/target + deviations + decisions
- Reporting scope + workstreams + management focus
- Status rows + actual progress + target markers + deviation explanation
- Delivery table + evidence completeness + stage conclusion
- KPI overview + comparison chart + driver analysis + action
- Risk table + distribution + governance cadence
- Decision table + recommendation + post-decision state
- Four-week plan + governance rhythm + execution requirements

## Remix controls

- More senior: reduce decoration and show fewer, more consequential decisions.
- More operational: add owners, dates, dependencies, and status markers.
- More financial: strengthen tabular alignment and variance logic.
- More institutional: add a restrained cover motif and more formal metadata.

## Failure signals

Headlines dominate the page; rows are tall while text is tiny; the body begins immediately under the title; the lower third is unused; excessive rounded cards make the report feel like a dashboard; status colors become decorative rather than semantic.
