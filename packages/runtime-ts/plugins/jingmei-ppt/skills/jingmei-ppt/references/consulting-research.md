# Consulting research recipe

## Visual thesis

Analytical, compressed, and calm. Make the slide feel like a decision document: conclusion first, evidence second, implication always visible.

## Signature

- Use a one-line claim headline and a restrained section label.
- Favor white or cool-neutral backgrounds, dark ink, navy or teal evidence colors, and thin gray rules.
- Build dense evidence grids with two to four coordinated regions rather than isolated decorative cards.
- Use charts, exact comparison tables, key statistics, and a concise management implication on the same page when they answer one question together.
- Keep sources and methodological caveats visible but subordinate.

## Typography and rhythm

Use assertive but not oversized headlines. Let body text remain compact and highly legible. Align labels and values precisely. Create a clear pause between the headline and the top border of the evidence field. Extend the lowest useful module close to the source band so the page does not feel top-heavy.

## Useful silhouettes

- Narrative bullets + chart + statistics + actions
- Two charts + key statistics + capability matrix
- Market map + comparison chart + implications
- Waterfall + drivers + assumptions + sensitivity
- Scenario columns + cross-scenario comparison table
- Recommendation table + validation thresholds + implementation cadence

## Remix controls

- More corporate: reduce teal, emphasize navy and gray.
- More contemporary: use larger claim text, fewer borders, and one vivid evidence accent.
- More academic: increase methodological annotation and neutralize color.
- More executive: shorten explanatory copy and strengthen decisions, owners, and thresholds.

## Failure signals

The page feels loose despite containing little evidence; the headline touches the first panel; every module has equal visual weight; charts lack an adjacent interpretation; sources are unreadable; density is achieved only through tiny type.
